# TEALOPER — وب‌سایت پورتفولیو

وب‌سایت شخصی سینا میرهادی با صحنه سه‌بعدی (Three.js و React Three Fiber). محتوای اصلی بدون WebGL هم نمایش داده می‌شود.

## اجرا

```bash
npm install
npm run dev
```

## ساخت نسخه تولید

```bash
npm run build
```

خروجی در پوشه `dist` ساخته می‌شود.

## انتشار روی Cloudflare Pages

- Build command: `npm run build`
- Build output directory: `dist`
- Production branch: `main`
- بعد از ساخت پروژه، دامنه `tealoper.ir` را در بخش Custom domains همان پروژه اضافه کنید و رکورد DNS را طبق راهنمای Cloudflare تنظیم کنید.

## ویرایش محتوا

- اطلاعات تماس و لینک تلگرام: `src/data/profile.ts`
- پروژه‌ها: `src/data/projects.ts` (برای افزودن پروژه، یک شیء جدید اضافه کنید)
- خدمات و مهارت‌ها: `src/data/content.ts`
- تنظیمات صحنه سه‌بعدی: `src/three/Scene.tsx`

## موارد باز

- لینک صفحه رسمی اپلیکیشن «سررشته» در مایکت هنوز تأیید نشده است. تا تأیید، لینک در `projects.ts` خالی است.
- شرح قابلیت‌ها و تصاویر واقعی سررشته به‌زودی اضافه می‌شود.
- فایل فونت Vazirmatn باید در `public/fonts` قرار بگیرد و با `@font-face` بارگذاری شود تا سایت به فونت خارجی وابسته نباشد.
- فایل رزومه PDF هنوز اضافه نشده است.

## افزودن نمونه‌کار جدید

فقط یک شیء به آرایهٔ `projects` در `src/data/projects.ts` اضافه کن:

```ts
{
  id: 'my-project',            // شناسهٔ یکتا (در آدرس #work/my-project استفاده می‌شود)
  name: 'عنوان پروژه',
  category: 'وب‌سایت',
  description: 'توضیح کوتاه',
  longDescription: 'توضیح کامل‌تر',
  tech: ['React'],
  url: 'https://example.com',  // اختیاری
  status: 'در حال توسعه',        // اختیاری
  images: ['/images/my-project-1.png'], // اختیاری؛ اگر نباشد قاب ساده نمایش داده می‌شود
}
```

کارت لایه‌ای نمونه‌کار و ارتفاع بخش نمونه‌کارها خودکار از این آرایه محاسبه می‌شوند.
نکته: مسیرهای دوربین سه‌بعدی (`src/three/timeline.ts`) فقط برای پروژه‌هایی که در `ANCHORS` مختصات دارند تعریف شده‌اند؛ پروژهٔ جدید بدون این مختصات در کارت‌ها نمایش داده می‌شود، ولی در صحنهٔ سه‌بعدی دوربین به سمتش نمی‌رود.

## موسیقی پس‌زمینه

فایل موسیقی را که مجوز استفاده دارد در مسیر `public/audio/ambient.mp3` قرار بده.
تا وقتی این فایل نباشد، کنترل موسیقی نمایش داده نمی‌شود. مرورگرها معمولاً پخش خودکار صدا را مسدود می‌کنند،
برای همین موسیقی با اولین کلیک یا کلید کاربر شروع می‌شود و کاربر همیشه می‌تواند آن را خاموش کند.

## لوگوتایپ ورودی

کلمهٔ TeaLoper با مربع‌ها در `src/three/LogoIntro.tsx` ساخته می‌شود. با اسکرول از بخش اول، مربع‌ها از هم جدا می‌شوند.
برای تغییر متن، فونت پیکسلی `GLYPHS` را ویرایش کن.
